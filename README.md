# 안개 속 프로필 — DBD Korea Profile Card

Dead by Daylight 한국 커뮤니티에서 사용할 수 있도록 만든 **비공식 정적 웹 프로필 카드 생성기**입니다.
빌드 과정이나 별도 백엔드가 필요 없으며 GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있습니다.

## 주요 기능

- 2026-10-07 공개 로스터 기준 생존자 54명 / 살인마 44명 검색 및 선택
- 한국어 + 영문 이름 동시 검색
- 생존자·살인마 각각 최대 8명 선택
- 이름, 친구 코드, 접속 시간, 플레이 스타일, 최고 등급, 플랫폼, Discord VC, 한마디 입력
- Steam / PlayStation / Xbox / Switch / Epic Games / Microsoft Store 로고 표시
- 잿빛·청동·은빛·금빛·핏빛 I~IV 등급 배지
- 안개 / 블러드 레드 / 딥 네이비 테마
- **1600×1600 (1:1)** 실시간 Canvas 미리보기 및 PNG 저장
- LocalStorage 자동 저장
- URL 해시 기반 공유 링크
- PC / 태블릿 / 모바일 반응형 UI
- PWA(Service Worker) 기반 오프라인 사용 지원

## 온라인에서 오프라인 준비하기

GitHub Pages처럼 HTTPS로 배포한 사이트에서는 **오프라인 사용 준비** 버튼을 한 번 누르면 앱 본체와 현재 캐릭터 초상화 98개를 브라우저 캐시에 저장합니다.
저장이 끝난 뒤에는 인터넷이 끊겨도 같은 브라우저에서 사이트를 다시 열어 프로필을 작성하고 PNG를 만들 수 있습니다.

> 처음 캐시를 만드는 순간에는 인터넷 연결이 필요합니다. 브라우저의 사이트 데이터/캐시를 삭제하면 다시 준비해야 합니다.

## ZIP을 PC에서 완전히 오프라인으로 사용하기

1. ZIP 압축을 풉니다.
2. 인터넷이 연결된 상태에서 `초상화_오프라인_저장.bat`를 한 번 실행합니다.
3. `assets/portraits`에 S01~S54, K01~K44 PNG가 생성되면 준비 완료입니다.
4. 이후 `index.html`을 직접 열면 캐릭터 초상화까지 로컬 파일을 우선 사용합니다.

초상화 파일이 없는 경우에는 온라인 이미지 소스로 자동 대체합니다.

## 모바일

모바일 화면에서는 입력 폼과 캐릭터 목록이 한 열로 배치되고 플랫폼 버튼·테마·액션 버튼이 터치하기 쉬운 크기로 변경됩니다.
GitHub Pages로 배포하면 Android/iOS 브라우저에서도 사용할 수 있으며, 지원 브라우저에서는 홈 화면에 웹앱 형태로 추가할 수 있습니다.

## 권장 공개 구성

- **GitHub Pages**: 실제 프로필 카드 생성기 실행
- **Notion Site**: 소개, 사용법, 업데이트 내역, 웹앱 링크, 오프라인 ZIP 다운로드 링크를 정리하는 안내 페이지

즉, Notion을 메인 안내 페이지로 쓰고 실제 생성기는 GitHub Pages에서 실행하는 구성을 권장합니다.

## 이미지 및 권리 안내

Dead by Daylight 및 관련 명칭·캐릭터·이미지의 권리는 Behaviour Interactive 및 각 라이선스 권리자에게 있습니다. 본 프로젝트는 비공식 팬메이드 도구이며 Behaviour Interactive의 공식 서비스가 아닙니다. 공개 운영 전에는 관련 팬 콘텐츠/브랜드 사용 정책을 확인하세요.


## v5 PNG 저장 안정화
- `index.html`을 직접 열었을 때 플랫폼/등급 로컬 이미지 때문에 Canvas가 보안 오염되는 문제를 피하기 위해, PNG 내보내기용 정적 이미지를 `embedded-assets.js`에 내장했습니다.
- 완전 오프라인 사용을 원하면 `초상화_오프라인_저장.bat`를 인터넷 연결 상태에서 한 번 실행하세요. 98명의 초상화를 내려받은 뒤 `portrait-data.js`를 자동 생성합니다. 이후 `index.html`을 직접 열어도 초상화 표시와 PNG 저장이 인터넷 없이 동작합니다.
- PlayStation 로고 오른쪽의 붉은 잔여 픽셀을 제거했습니다.


## v6 — 1:1 SNS 레이아웃

- 카드 출력 규격을 1600×900(16:9)에서 **1600×1600(1:1)** 로 변경했습니다.
- X(트위터), Discord, 모바일 공유를 고려해 정보 밀도를 높인 정사각형 전용 레이아웃으로 재설계했습니다.
- 상단 프로필 정보 → 생존자/살인마 등급 → 플랫폼/VC → 주 사용 캐릭터 4×2 → 한마디 순서로 배치했습니다.
- 생존자와 살인마는 각각 최대 8명까지 4×2 그리드로 표시됩니다.
- 캐릭터 초상화 하단에 한국어 이름을 오버레이합니다.
- 기존 모바일 반응형, PWA 오프라인 저장, 공유 링크, PNG 저장 기능은 유지됩니다.
- Service Worker 캐시를 v6로 갱신해 GitHub Pages 업데이트 시 새 UI가 반영되도록 했습니다.
